# Bookmark Directory Analytics

Техническая документация проекта для анализа структуры закладок браузера.

Приложение работает с базой `places.sqlite`, используемой браузерами Firefox-совместимого семейства, и формирует текстовый отчёт по выбранной папке закладок. Поддерживаются консольный запуск, HTTP API на FastAPI и HTML-интерфейс.

## Требования

- Python `>=3.14`;
- [uv](https://github.com/astral-sh/uv);
- браузер Floorp или совместимый профиль с базой `places.sqlite`.

Зависимости проекта объявлены в `pyproject.toml`:

- `aiosqlite`;
- `fastapi[standard]`;
- `colorama`;
- `pyinstaller`.

## Установка

```bash
git clone https://github.com/VortexOwl/bookmark-directory-analytics.git
cd bookmarks-checker
uv sync
```

## Архитектура

Основные компоненты:

- `src/start.py` — точки входа консольных команд;
- `src/config.py` — конфигурация приложения и Uvicorn;
- `src/app/database.py` — копирование базы и работа с SQLite;
- `src/app/report.py` — сервисы формирования и очистки отчётов;
- `src/web/router.py` — FastAPI-приложение и HTTP-маршруты;
- `src/templates/` — HTML-шаблоны пользовательского интерфейса.
- `src/static/` —CSS-стили пользовательского интерфейса.

### Формирование отчёта

`ReportService.generate_report()` выполняет следующие операции:

1. Проверяет путь к исходной базе браузера.
2. Копирует `places.sqlite` в каталог `data`.
3. Открывает локальную копию базы через `aiosqlite`.
4. Ищет папку по полю `title` таблицы `moz_bookmarks`.
5. Подсчитывает закладки и дочерние папки.
6. Возвращает текст отчёта.
7. При `is_save_file=True` создаёт каталог отчётов и сохраняет файл.

Если путь к профилю не определён, используется ранее сохранённый файл базы в каталоге `data`, если он существует.

Анализ выполняется для исходной папки и её непосредственных дочерних папок. Более глубокие уровни вложенности не обходятся рекурсивно.

## Консольные команды

Команды объявлены в секции `[project.scripts]` файла `pyproject.toml`.

| Команда     | Точка входа            | Назначение                                                                                                |
| ------------------ | -------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `uv run start`   | `start:start_web`             | Запуск веб-сервера                                                                                  |
| `uv run default` | `start:start_default_config`  | Формирование и сохранение отчёта с конфигурацией по умолчанию |
| `uv run clear`   | `start:start_clear`           | Очистка каталога отчётов                                                                      |

### Формирование отчёта

```bash
uv run default
```

По умолчанию отчёт сохраняется в:

```text
report/Bookmarks KDE Store.txt
```

### Запуск веб-сервера

```bash
uv run start
```

По умолчанию сервер доступен по адресу:

```text
http://127.0.0.1:8000
```

Интерактивная документация FastAPI:

```text
http://127.0.0.1:8000/docs
```

### Очистка отчётов

```bash
uv run clear
```

Команда удаляет файлы из каталога, заданного параметром `report_folder`. По умолчанию используется каталог `report`.

## Конфигурация приложения

Класс `Config` находится в `src/config.py`. Переменные окружения используют префикс `APP_`.

| Параметр                  | Значение по умолчанию | Назначение                                             |
| --------------------------------- | ---------------------------------------- | ---------------------------------------------------------------- |
| `log_level`                    | `10`                                  | Уровень журналирования                      |
| `is_open_webbrowser`           | `True`                                | Открывать веб-интерфейс в браузере |
| `bookmarks_folder`             | `KDE Store`                           | Имя анализируемой папки                     |
| `browser`                      | `Floorp`                              | Имя браузера                                          |
| `browser_folder`               | `.floorp`                             | Каталог профилей браузера в Linux        |
| `custom_name_browser_profile`  | `None`                                | Имя профиля браузера                           |
| `custom_name_report_file`      | `None`                                | Пользовательское имя отчёта             |
| `database_file`                | `places.sqlite`                       | Имя файла базы данных                          |
| `data_folder`                  | `data`                                | Каталог локальной копии базы            |
| `report_folder`                | `report`                              | Каталог отчётов                                    |

### Производные пути

- `patch_data_folder` — путь к каталогу данных;
- `path_data_file` — `<data_folder>/<database_file>`;
- `path_report_folder` — путь к каталогу отчётов;
- `name_report_file` — пользовательское имя или `Bookmarks <bookmarks_folder>`;
- `path_report_file` — `<report_folder>/<name_report_file>.txt`;
- `path_browser_profile` — путь к профилю браузера;
- `path_source_database` — путь к исходной базе `places.sqlite`.

### Поиск профиля браузера

В Windows используется путь:

```text
%USERPROFILE%/AppData/Roaming/<browser>/Profiles/
```

В Linux используется:

```text
$HOME/<browser_folder>/
```

Если `custom_name_browser_profile` не задан, выбирается первый каталог, соответствующий шаблону:

```text
*.default*
```

Поддерживаются Windows и Linux. Для других операционных систем путь к профилю не определяется.

### Конфигурация Uvicorn

Класс `ServerConfig` использует префикс `SERVER_`.

| Параметр | Значение по умолчанию | Назначение                                  |
| ---------------- | ---------------------------------------- | ----------------------------------------------------- |
| `host`        | `127.0.0.1`                           | Адрес сервера                             |
| `port`        | `8000`                                | Порт сервера                               |
| `is_reload`   | `True` вне frozen-сборки     | Автоматическая перезагрузка |
| `access_log`  | `True` вне frozen-сборки     | Журналирование запросов         |

В Docker-контейнере автоматически устанавливаются:

```text
host=0.0.0.0
is_reload=False
```

## HTTP API

### `GET /`

Перенаправляет на HTML-форму анализа:

```text
/directory-analytics/new
```

### `GET /directory-analytics/report`

Формирует отчёт по выбранной папке.

Query-параметры:

| Имя параметра | Обязательность | Значения                   |
| ------------------------- | ---------------------------- | ---------------------------------- |
| `saving file`          | обязательно       | `Да` или `Нет`      |
| `bookmarks folder`     | необязательно   | Имя папки закладок |

Пример:

```text
GET /directory-analytics/report?saving%20file=Нет&bookmarks%20folder=KDE%20Store
```

Поведение:

- `saving file=Нет` — возвращается `text/plain`;
- `saving file=Да` — отчёт сохраняется и возвращается как `FileResponse`;
- HTML-запросы получают HTML-страницу с результатом.

Коды ответов API:

- `200 OK` — отчёт сформирован;
- `400 Bad Request` — указанная папка отсутствует в базе;
- `404 Not Found` — база закладок не найдена.

Сообщение об отсутствии базы:

```text
По указанному пути отсутствует файл базы данных закладок.
```

При запуске в Docker сообщение дополнительно содержит указание разместить базу в примонтированном каталоге `data`.

### `POST /update-config`

Изменяет параметры конфигурации.

Поля `form-data`:

| Поле                     | Описание                                                                                                           |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `browser`                 | Браузер; доступно значение`Floorp`                                                               |
| `bookmarks folder`        | Имя папки закладок                                                                                         |
| `custom browser profile`  | Имя профиля браузера                                                                                     |
| `name report file`        | Имя файла отчёта без расширения                                                                 |
| `is default`              | `Да` — сбросить настройки, `Нет` — изменить переданные параметры |

Пустые значения не изменяют текущую конфигурацию.

Для API-запроса возвращается JSON:

```json
{
  "browser": "Floorp",
  "bookmarks_folder": null,
  "browser_profile": null,
  "custom_report_file": null,
  "is_default": "Нет"
}
```

HTML-запрос получает страницу подтверждения.

### `POST /cleanup`

Удаляет файлы из каталога `report_folder`.

API-ответ:

```json
{
  "status": "ok",
  "message": "Ручка очистки директории отчетов от файлов доступна через POST /cleanup",
  "report": {
    "success": 1,
    "errors": 0,
    "names of errors": []
  }
}
```

Если каталог отчётов отсутствует, операция завершается с нулевой статистикой удаления.

### `GET /shutdown`

Устанавливает флаг завершения Uvicorn-сервера.

Для обычного API-запроса возвращается:

```json
{
  "status": "ok",
  "message": "Запрос на остановку сервера отправлен"
}
```

HTTP-статус ответа — `202 Accepted`.

### HTML-маршруты

| Маршрут                     | Назначение                               |
| ---------------------------------- | -------------------------------------------------- |
| `GET /directory-analytics/new`  | Форма анализа закладок         |
| `GET /update-config`            | Форма настройки приложения |
| `GET /cleanup`                  | Форма очистки отчётов           |

## Формат отчёта

Пример:

```text
Initial catalog: KDE Store
bookmarks: 0
catalogs: 2
---------------------------------------------------------------------------------------------
Глобальные темы
bookmarks: 3
---------------------------------------------------------------------------------------------
Заставки
bookmarks: 1
```

В базе Firefox используются следующие типы записей:

- `type=1` — закладка;
- `type=2` — папка.

Считаются только непосредственные дочерние элементы текущей папки.
