# 🔎 Bookmark Directory Analytics

> Приложение для анализа количества закладок и структуры вложенных папок в браузере **Floorp**.>
> Это полезно, когда у вас много закладок и нужно быстро проверить их структуру или узнать, сколько ссылок лежит в конкретной папке.
> Программа запускается через веб-интерфейс и автоматически создаёт текстовый отчёт с результатами анализа.

## ✨ Возможности

- **Кроссплатформенность:** полная поддержка операционных систем Windows и Linux.
- **Анализ закладок:** сканирование выбранной папки, подсчет количества ссылок и определение структуры вложенных папок.
- **Экспорт данных:** автоматическое сохранение сформированного отчета в текстовый файл.
- **Резервный источник данных:** анализ папки закладок указанной в конфигурации, если основное поле ввода осталось пустым.
- **Гибкая конфигурация:** возможность переопределить папку закладок, профиль браузера и имя файла отчета.
- **Управление архивом:** ручная очистка директории с ранее созданными отчетами средствами приложения.

## 📥 Установка

Готовые версии приложения доступны на странице Releases.

Выберите архив в зависимости от вашей операционной системы:

| Операционная система | Архив                                                                       |
| --------------------------------------- | -------------------------------------------------------------------------------- |
| Linux                                   | [bmd-analytics-linux.zip](../../releases/latest/download/bmd-analytics-linux.zip) |
| Windows                                 | [bmd-analytics-win.zip](../../releases/latest/download/bmd-analytics-win.zip)     |

Распакуйте скачанный архив в удобную папку.

## 🚀 Запуск

### Windows

1. Скачайте архив `bmd-analytics-win.zip`.
2. Распакуйте архив.
3. Откройте распакованную папку.
4. Запустите файл `bmd-analytics.exe`.
5. В выбранном по умолчанию браузере откроется адрес:

   ```text
   http://localhost:8000/directory-analytics/new
   ```

Чтобы остановить приложение, используйте кнопку **«Остановить сервер приложения»** в веб-интерфейсе, нажмите в окне запущенной программы сочетание клавиш `Ctrl+C` или закройте её.

### Linux

1. Скачайте архив `bmd-analytics-linux.zip`.
2. Распакуйте архив.
3. Перейдите в распакованную папку.
4. Сделайте файл приложения исполняемым:

   ```bash
   chmod +x bmd-analytics
   ```
5. Запустите приложение:

   ```bash
   ./bmd-analytics
   ```
6. В выбранном по умолчанию браузере откроется адрес:

   ```text
   http://localhost:8000/directory-analytics/new
   ```

## 🌐 Подготовка браузера

Перед запуском анализа убедитесь, что браузер Floorp установлен и в нём сохранены закладки.

Приложение ищет базу закладок в профиле Floorp:

- Windows:

  ```text
  %USERPROFILE%\AppData\Roaming\Floorp\Profiles\<профиль>\places.sqlite
  ```
- Linux:

  ```text
  $HOME\.floorp\<профиль>\places.sqlite
  ```

Профиль выбирается автоматически. Используется первый найденный профиль, имя которого соответствует шаблону `*.default*`.

### Важно

Приложение не изменяет исходную базу браузера. Оно копирует файл `places.sqlite` в локальную папку `data` и работает с этой копией.

## 📝 Создание отчёта

На странице **«Анализ директории закладок»**:

1. Введите точное название папки закладок.
2. Выберите вариант **«Да»** или **«Нет»** в поле сохранения результата.
3. Нажмите **«Провести анализ директории»**.

Если выбрано **«Нет»**, отчёт будет отображен на открытой странице.

Если выбрано **«Да»**, отчёт будет доступен к загрузке как текстовый файл.

По умолчанию используется папка закладок ``KDE Store``.

Название должно совпадать с названием папки в браузере.

## 📄 Формат отчёта

Пример результата:

```text
Initial catalog: KDE Store
bookmarks: 0
catalogs: 2
---------------------------------------------------------------------------------------------
Глобальные темы
bookmarks: 3
---------------------------------------------------------------------------------------------
Заставки
bookmarks: 1
```

В отчёте:

- `bookmarks` — количество закладок;
- `catalogs` — количество вложенных папок;
- `Initial catalog` — исходная папка закладок.

Приложение проводит анализ количества закладок в выбранной папке и определение структуры её дочерних папках.

## ⚙ Конфигурация приложения

На странице **«Настроить конфигурацию»** доступны следующие параметры:

| Название                            | Описание                                                                                                    | Пример            |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| Браузер                              | Поддерживается браузер`Floorp`                                                               | `Floorp`              |
| Папка закладок                 | Название папки, для которой нужно провести анализ её структуры | `KDE Store`           |
| Путь к профилю браузера | Путь к пользовательскому профилю браузера                                      | `<path/to/profile>`   |
| Название файла отчёта    | Имя для файла отчета без расширения                                                   | `Bookmarks KDE Store` |

### Сброс настроек

Кнопка **«Установить значения по умолчанию»** возвращает следующие значения:

- браузер — `Floorp`;
- папка закладок — `KDE Store`;
- профиль — автоматический выбор;
- имя отчёта — `Bookmarks <папка закладок>`.

## 🧹 Очистка отчётов

На странице **«Очистка папки отчётов»**:

1. Нажмите кнопку **«Очистить папку»**;
2. Откроется страница **«Результат очистки»**, где отобразится отчет о проделанной работе.

Будут удалены файлы из папки `report`.

## 📁 Файлы приложения

После запуска рядом с приложением могут появиться следующие папки:

| Папка | Назначение                                      |
| ---------- | --------------------------------------------------------- |
| `data`   | Локальная копия базы`places.sqlite`  |
| `report` | Сохранённые текстовые отчёты    |

При запуске приложение автоматически обновляет файл базы данных в папке `data`. Если обновить файл невозможно, используется его предыдущая локальная копия.

## 🐞 Частые проблемы

### Не найден файл базы закладок

Сообщение:

```text
По указанному пути отсутствует файл базы данных закладок.
```

Проверьте:

- установлен ли `Floorp`;
- существует ли профиль `Floorp`;
- правильно ли указано имя профиля;
- есть ли файл `places.sqlite` в папке профиля.

Если профиль не определяется автоматически, укажите путь к нему в конфигурации приложения.

### Папка не найдена

Если приложение сообщает, что папка отсутствует в базе данных закладок, проверьте:

- правильность написания названия;
- регистр символов;
- отсутствие лишних пробелов в названии.

### Веб-страница не открылась автоматически

Скопируйте и откройте в браузере любой из адресов:

- `http://localhost:8000`.
- `http://localhost:8000/directory-analytics/new` .

### Порт уже используется

Если адрес `localhost:8000` недоступен, закройте другой экземпляр приложения или программу, которая использует порт `8000`.
